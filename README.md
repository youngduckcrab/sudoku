# 스도쿠 (오프라인)

설치·빌드 없이 동작하는 오프라인 스도쿠 웹앱(PWA)입니다.

## 기능

- **완전 오프라인**: 외부 라이브러리·네트워크 요청 없음. 한 번 열면 서비스 워커가 모든 파일을 캐시하고, 휴대폰에서는 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.
- **난이도 2단계**: `어려움`, `매우 어려움`. 퍼즐은 기기에서 즉석으로 생성하고, 내장 풀이 엔진으로 난이도를 판정합니다. 생성이 늦으면 내장 퍼즐 은행(각 300개)을 무작위로 변형해 사용합니다.
  - 어려움: 포인팅·클레이밍, 네이키드/히든 페어·트리플이 필요한 퍼즐
  - 매우 어려움: X-윙, 스카이스크래퍼, 투 스트링 카이트, XY-윙, XYZ-윙, W-윙, 소드피시, 유일 사각형, 색칠, X-체인, XY-체인 등이 필요한 퍼즐
  - 모든 퍼즐은 해가 하나뿐이고, 힌트 엔진의 기법만으로 끝까지 풀 수 있음이 보장됩니다.
- **후보 메모**: 메모 모드, 후보 자동 채우기, 숫자 입력 시 같은 행·열·박스 후보 자동 삭제(설정).
- **빠른펜**: 숫자를 먼저 고르고 칸을 누를 때마다 채웁니다. 메모와 함께 켜면 후보를 빠르게 기록하고, 칸 위를 문질러 여러 칸에 한 번에 후보를 넣거나 뺄 수 있습니다. 빠른펜에서 `지우기`는 지우개 펜이 됩니다.
- **기법 설명 힌트** (2단계)
  1. 사용할 기법 이름과 살펴볼 곳(행/열/박스)만 알려줍니다.
  2. `자세히 보기`: 어떤 칸의 어떤 후보를 **왜** 지울 수 있는지, 또는 어떤 칸에 어떤 숫자를 채울 수 있는지 설명하고, 판 위에 핵심 후보(초록/파랑)와 지울 후보(빨강)를 표시합니다. `적용하기`로 바로 반영합니다.
  - 틀린 숫자를 넣었거나 메모에서 정답 후보를 지웠다면 그것부터 알려줍니다.
- **오답 즉시 표시**: 후보에 있는 숫자라도 정답과 다르면 바로 빨갛게 표시하고 오답 횟수를 셉니다 (설정에서 끌 수 있음).
- 되돌리기/다시 실행, 충돌 표시, 같은 숫자 강조, 타이머, 자동 저장, 다크 모드, 키보드 조작.

## 실행

`index.html`을 브라우저로 바로 열어도 됩니다. 오프라인 캐시(서비스 워커)와 홈 화면 설치는 `http(s)`로 제공할 때 활성화됩니다.

```bash
python3 -m http.server 8000
```

그 뒤 `http://localhost:8000` 접속. GitHub Pages 등 정적 호스팅에 그대로 올려도 됩니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `js/core.js` | 판 구조, 후보 계산, 백트래킹 솔버(유일해 검사), 퍼즐 변형, 한국어 조사 보정 |
| `js/techniques.js` | 사람식 풀이 기법 22종. 각 기법은 지울 후보/채울 숫자와 한국어 설명을 반환 |
| `js/generator.js` | 퍼즐 생성 및 난이도 판정 |
| `js/puzzles.js` | 미리 생성한 퍼즐 은행 (`npm run generate`로 재생성) |
| `js/app.js` | UI, 입력, 힌트, 저장 |
| `sw.js` | 오프라인 캐시 — 파일을 바꾸면 `CACHE` 버전을 올리세요 |
